---
## Commands:

1. mkdir< folder name >: ***Create an empty folder***
- PS: `When created you wasn't inside the folder yet.`

examples:


```
mkdir zoo
```
---
2. touch< file >: ***Create empty files, samething***
- PS: `Samething, when being created, you are not inside the file.`

examples:


```
touch forest
```

---
3. ls -R : ***listing all directory files***
- PS: `Have to return at the very first system to show all directory files.`

examples:

```
ls -R =>
```
![ls example](https://miro.medium.com/1*_5v79sJylDH9l9ZkB40otw.jpeg)
---
4. cd< folder/file name > & cd .. : ***First command is to go inside a folder or file and the second one is to return the last folder or file you go into.***
- PS: `You have to put space between cd and .. inorder to let the command work.`

examples:

```
cd zoo
cd ..
```

---
5. pwd : ***Showing the current directory***
- PS: `Have similar function like ls but different.`

example

```
pwd => workplace/zoo(main)/forest
```
